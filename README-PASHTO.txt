د نړیوالې کچې Portfolio — د کارولو لارښود

1) د pritfolio-master/index.html فایل په Chrome کې خلاص کړه (د انلاین فونټونو، React، Chart.js او Font Awesome لپاره انټرنېټ ته اړتیا شته).
2) پنځه اصلي سرټیفیکټونه د certificates/ فولډر کې ساتل شوي دي؛ د Verify Credential لینکونه د index.html په certificates array کې دي.
3) لینکونه د ستا د سرټیفیکټونو له عکسونو څخه نقل شوي دي. د Coursera اوسنی فعال حالت په اتومات ډول نه دی تایید شوی؛ هر لینک په خپل براوزر کې وازمویه.
4) ټولې ۱۰ پروژې د project-art/ فولډر خپلواکې، محلي SVG Concept Illustrations لري؛ دا د حقیقي پروژو Screenshot نه دي. که خپل اصلي Screenshot لرې، د هماغې پروژې img فایل بدل کړه.
5) Weather Dashboard او Web Academy Platform د پروژو په پای کې اضافه شوي دي. د دوی tags د ښودلو لپاره وړاندیز شوي Stack دی؛ که حقیقي ټکنالوژي توپیر ولري، سم یې کړه.
6) PHP، Laravel، Bootstrap د Skills کارتونو، Chart، Hero او About برخو کې ځای لري. د SkillsChart سلنې د ډیزاین لپاره بېلګه دي؛ له خپلې واقعي تجربې سره یې سمې کړه.
7) د پروژو Filter: All projects / Web Apps / Data / Tools & Games.
8) د GitHub لینک اوس هم پخوانی placeholder دی (github.com/dashboard). د خپل عامه GitHub پروفایل لینک ورکړه.
9) په index.html کې د موبایل لپاره Responsive CSS شته؛ په Chrome DevTools کې 320px، 375px، 768px او 1440px وازمویه.
10) د سندونو د نومونو، عکسونو او لینکونو د بدلولو لپاره const certificates وپلټه؛ د پروژو لپاره const projects وپلټه.

دا HTML + React (CDN) پروژه ده؛ Laravel/PHP د مهارتونو په توګه ښکاري، خو Portfolio په PHP/Laravel backend نه دی بدل شوی.

11) د Technology Ecosystem نوی Doughnut Chart د ۱۳ ټکنالوژیو کټګورۍ ښيي؛ دا د مهارتونو سلنې نه دي.
